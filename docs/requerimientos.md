# Requerimientos
- Simulador Simpletron: carga SML desde archivo, ciclo de instrucción, registros, errores fatales
  (división entre cero, opcode inválido).
- Instrucciones: READ/WRITE (10/11), LOAD/STORE (20/21), ADD/SUBTRACT/DIVIDE/MULTIPLY (30-33),
  MODULO (34) y POTENCIA (35) como extensiones, BRANCH/BRANCHNEG/BRANCHZERO (40-42), HALT (43).
- Expresiones: balance de paréntesis, infija a postfija, precedencia y asociatividad.
- Compilador Simple a SML en dos pasadas, con tabla de símbolos.
